# LetsDoc 文书模板生成器

LetsDoc 是一个纯前端、本地处理的文书模板生成工具，支持基于 `.docx` 模板进行单份和批量文书生成。

所有文件处理均在浏览器中完成，不上传服务器，不保存数据。

## 支持的文件格式

| 类型 | 支持 | 不支持 | 说明 |
|------|------|--------|------|
| 模板 | `.docx` | `.doc` | .doc 需先另存为 .docx |
| 数据 | `.xlsx` | `.xls` | 网页录入无需 Excel |

## 启动命令

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`

## 构建命令

```bash
npm run build
```

产物在 `dist/` 目录。

## 模板制作方法

1. 在 Word 中创建 `.docx` 文件
2. 在需要替换的位置输入 `{{变量名}}`，例如 `{{姓名}}`、`{{日期}}`
3. 变量名只允许：中文、英文、数字、下划线
4. 建议一次性输入完整占位符，不要分多次输入

### 正确示例

- `{{姓名}}`
- `{{单位名称}}`
- `{{日期}}`
- `{{doc_no}}`

### 错误示例

- `{{单位 名称}}`（变量名含空格）
- `{{单位-名称}}`（变量名含连字符）
- `{{}}`（空变量名）

## 模板体检

上传模板后，系统会自动进行体检，检查模板质量并给出诊断结果。

### 检查项目

| 级别 | 检查项 | 说明 |
|------|--------|------|
| 错误 | 无变量模板 | 模板中未识别到变量 |
| 错误 | 非法变量名 | 变量名包含非法字符 |
| 错误 | 未闭合占位符 | 检测到未闭合的「{{」或孤立的「}}」 |
| 警告 | 跨 run 占位符 | 变量可能被 Word 拆分 |
| 警告 | 相似变量名 | 变量名高度相似，可能是误写 |
| 提示 | 重复变量 | 同一变量出现多次 |
| 提示 | 变量数量较多 | 变量数量超过 20 个 |
| 提示 | 页眉页脚变量 | 页眉或页脚中包含变量 |

### 体检结果

- 体检通过：模板未发现明显问题
- 存在警告：可能影响生成，建议检查
- 存在错误：可能无法正常生成，请先修复

## 单份生成流程

1. 上传 `.docx` 模板
2. 系统自动识别模板中的变量
3. 填写变量值
4. 点击「生成文书」
5. 下载生成的 `.docx` 文件

## 批量生成流程

### 方式一：网页手工录入

1. 上传 `.docx` 模板
2. 在「批量生成」区域选择「网页录入」标签
3. 在可编辑表格中填写数据（每行一份文书）
4. 支持新增行、复制上一行、删除行、清空数据
5. 支持从 Excel 复制多行多列后粘贴到表格
6. 点击「校验数据」检查空值
7. 点击「批量生成」下载 `.zip` 文件

### 方式二：Excel 导入

1. 上传 `.docx` 模板
2. 在「批量生成」区域选择「Excel 导入」标签
3. 点击「下载数据模板」获取 Excel 模板（列头为变量名）
4. 或点击「下载示例 Excel」获取示例数据
5. 在 Excel 中填写数据（每行一份文书）
6. 上传填写好的 `.xlsx` 文件
7. 系统显示数据校验结果（行数、空值、缺失列等）
8. 点击「开始批量生成」
9. 下载打包的 `.zip` 文件

## 常见错误和解决方法

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| 模板中未发现占位符变量 | 模板中没有 `{{变量名}}` | 在 Word 中使用 `{{变量名}}` 格式 |
| 变量名 "xxx" 包含非法字符 | 变量名含有空格、连字符等 | 只使用中文、英文、数字、下划线 |
| 无法解析 .docx 文件 | 文件可能损坏或不是 .docx | 重新保存为 .docx 格式 |
| Excel 缺少以下变量列 | Excel 表头缺少模板中的变量 | 在 Excel 中补充缺失的列 |
| 第 N 行缺少必填值 | 某行的某个变量列为空 | 填写该行的空值列 |
| 当前版本最多支持一次生成 500 份 | Excel 数据超过 500 行 | 拆分 Excel 分批处理 |
| 模板渲染失败 | 占位符可能被 Word 拆分 | 删除占位符后重新一次性输入 |

## 本地模板库

支持将上传的 `.docx` 模板保存到当前浏览器本地，下次打开网页可直接选择使用，无需重新上传。

### 功能说明

- **保存模板**：上传模板后点击「保存到本地模板库」按钮
- **选择模板**：在本地模板库列表中点击「选择」按钮
- **重命名模板**：点击编辑图标修改模板名称
- **删除模板**：点击删除图标移除单个模板
- **清空模板库**：点击「清空」按钮移除所有模板
- **导出模板库**：点击「导出模板库」按钮，下载 `.letsdoc` 备份文件
- **导入模板库**：点击「导入模板库」按钮，选择 `.letsdoc` 或旧版 `.doclet` 文件导入

### 数据存储

- 模板文件保存在浏览器 IndexedDB 中
- 不会上传到任何服务器
- 不需要用户新建文件夹
- 清理浏览器数据、换电脑或换浏览器后，模板库会丢失
- 换电脑、换浏览器不会同步
- 建议保留原始 `.docx` 文件备份

### 常用值存储

- 常用变量值保存在浏览器 localStorage 中
- 不会上传到任何服务器
- 清理浏览器数据后会丢失
- 每个变量最多保存 10 个常用值

### 行为说明

- **保存同一模板多次**：同名模板会被覆盖更新，不会产生重复记录
- **删除当前使用的模板**：模板从库中删除，但当前内存中的模板仍可继续使用，直到刷新页面
- **清空模板库**：所有模板从库中删除，当前使用的模板仍可继续使用，直到刷新页面

### 使用流程

1. 上传 `.docx` 模板 → 识别变量
2. 点击「保存到本地模板库」
3. 下次打开网页 → 从本地模板库选择模板
4. 直接填写数据或恢复草稿 → 生成文书

### 模板库备份与恢复

支持将本地模板库导出为 `.letsdoc` 备份文件，并在以后或其他浏览器中重新导入。新版备份文件使用 `.letsdoc` 格式，仍兼容导入旧版 `.doclet` 文件。

#### 导出模板库

1. 点击「导出模板库」按钮
2. 系统生成 `.letsdoc` 备份文件并下载
3. 文件名格式：`letsdoc-template-library-YYYYMMDD-HHmm.letsdoc`

#### 导入模板库

1. 点击「导入模板库」按钮
2. 选择 `.letsdoc` 或旧版 `.doclet` 文件
3. 系统显示导入预览（总数、新增、同名覆盖）
4. 确认后导入

#### `.letsdoc` / `.doclet` 文件说明

- `.letsdoc` 是 LetsDoc 专用备份格式，本质是 zip 文件
- 新版导出使用 `.letsdoc` 格式，仍兼容导入旧版 `.doclet` 文件
- 包含 `manifest.json`（元数据）和 `templates/` 目录（模板文件）
- 包含 Word 模板文件本体，请妥善保存，不要随意发送给他人
- 请仅导入你信任来源的 `.letsdoc` 或 `.doclet` 文件

#### 冲突处理

- 同名模板会覆盖当前本地模板库中的已有模板
- 导入前会显示同名模板数量

## 当前限制

- 仅支持 `.docx` 模板，不支持 `.doc`
- 仅支持 `.xlsx` 数据文件，不支持 `.xls`
- 批量生成最多 500 行
- 不支持跨 XML run 的占位符（如 `{{姓` + `名}}`）
- 刷新页面需重新上传模板
- 不支持 PDF 导出
- 不支持在线编辑模板

## 关于 .doc 文件

当前版本不支持 `.doc` 格式模板。`.doc` 是旧版 Word 二进制格式，无法稳定通过当前技术方案处理。

如需使用 `.doc` 模板，请先用 Word/WPS/LibreOffice 打开文件，然后「另存为」选择 `.docx` 格式保存，再上传到本工具。

不建议在后续版本引入自动 `.doc` 转换，以免引入格式风险。

## 技术栈

- Vite + React 19 + TypeScript 6
- Ant Design 6
- docxtemplater（Word 模板渲染）
- PizZip（.docx 解压/打包）
- SheetJS（Excel 读写）
- IndexedDB（本地模板库存储）
- JSZip（批量打包）
- FileSaver（文件下载）

## 分发与部署

本工具是纯前端应用，所有文件处理在浏览器中完成，用户文件不会上传到任何服务器。

### 生产构建

```bash
npm run build
```

构建产物在 `dist/` 目录。

### 本地预览

```bash
npm run preview
```

浏览器打开 `http://localhost:4173` 预览生产构建。

### 静态部署

将 `dist/` 目录部署到任意静态网站服务即可：

- **公网部署**：GitHub Pages、Cloudflare Pages、Netlify、Vercel
- **内网部署**：单位内网静态服务器、Nginx、Apache、IIS
- **本地使用**：建议通过 `npm run preview` 启动本地服务器

不建议直接双击 `dist/index.html` 使用（部分浏览器会限制本地文件的 API 访问）。

非技术用户只需访问部署后的网址即可使用。

详细部署指南见 [docs/deploy.md](docs/deploy.md)。

## 桌面版

本工具支持通过 Electron 打包为桌面应用，双击即可使用。

### 桌面开发模式

```bash
npm run electron:dev
```

自动构建网页并打开桌面窗口。

### 桌面打包

```bash
npm run electron:build
```

打包产物在 `release/` 目录。

### 注意事项

- 未签名应用可能被系统拦截，需在「系统设置 → 隐私与安全性」中允许运行
- macOS：右键点击应用 → 打开
- 桌面版功能与网页版完全一致
- 用户文件仍通过上传/选择文件进入处理，不会自动读取本地路径

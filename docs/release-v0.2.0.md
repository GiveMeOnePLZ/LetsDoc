# 文书模板生成器 V0.2.0 发布说明

发布日期：2026-06-14

## V0.2 新增功能

### 网页手工批量录入

新增可编辑表格，无需 Excel 即可批量录入数据：

- 每列为一个模板变量，每行为一份文书数据
- 默认显示 3 行空表格
- 支持新增行、复制上一行、删除行、清空数据
- 支持从 Excel 复制多行多列后粘贴到网页表格
- 粘贴时自动追加行、忽略多余列
- 校验后空行灰色背景、空值行红色背景
- 具体提示行号和缺少的字段名

### 批量生成 Tabs

批量生成区域分为两个标签：

- **网页录入**：直接在页面表格中填写数据
- **Excel 导入**：上传 .xlsx 文件（V0.1 功能）

### .doc 文件友好提示

上传 .doc 文件时显示：

> 当前版本暂不支持 .doc 模板。请先使用 Word/WPS/LibreOffice 将文件另存为 .docx 后再上传。为保证格式稳定，系统仅处理 .docx 模板。

## 当前限制

- 仅支持 `.docx` 模板
- 仅支持 `.xlsx` 数据文件（网页录入无需 Excel）
- 批量最多 500 行
- 不支持跨 XML run 占位符
- 刷新页面需重新上传模板

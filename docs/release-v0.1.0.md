# 文书模板生成器 V0.1.0 发布说明

发布日期：2026-06-14

## 项目定位

本地浏览器运行的公文/文书批量生成工具。所有文件处理在浏览器中完成，不上传服务器，不保存数据。

## V0.1 已支持功能

| 功能 | 说明 |
|------|------|
| 模板上传 | 拖拽或点击上传 `.docx` 模板文件 |
| 变量识别 | 自动识别 `{{变量名}}` 占位符，支持正文、表格、页眉、页脚 |
| 变量校验 | 变量名只允许中文、英文、数字、下划线 |
| 单份生成 | 手工填写变量值，生成单份 `.docx` |
| 批量生成 | 上传 `.xlsx`，每行生成一份 `.docx`，打包为 `.zip` |
| Excel 预校验 | 上传后显示行数、空行、缺列、多余列、空值详情 |
| 进度展示 | 批量生成时显示百分比进度条和文字提示 |
| 示例下载 | 提供示例 Excel 下载（含 2 行数据） |
| 模板说明 | 页面内置模板制作说明区域 |

## 当前不支持功能

- `.doc` 格式模板
- `.xls` 格式数据文件
- PDF 导出
- 在线 Word 编辑/预览
- 生成历史记录
- 多用户/权限/审批
- 后端/数据库
- 条件语句/循环
- 跨 XML run 占位符修复
- 套红排版

## 文件格式限制

| 类型 | 支持 | 不支持 |
|------|------|--------|
| 模板 | `.docx` | `.doc` |
| 数据 | `.xlsx` | `.xls` |
| 输出 | `.docx`、`.zip` | `.pdf` |

## 模板变量规则

- 格式：`{{变量名}}`
- 允许：中文、英文、数字、下划线
- 不允许：空格、连字符、点号、空变量名
- 变量按首次出现顺序去重
- 建议在 Word 中一次性输入完整占位符

正确示例：`{{姓名}}`、`{{单位名称}}`、`{{日期}}`、`{{doc_no}}`

错误示例：`{{单位 名称}}`、`{{单位-名称}}`、`{{}}`

## 批量生成限制

- 最多 500 行数据
- 超出时提示分批处理
- 空行自动跳过
- 文件名非法字符自动清理

## 已知风险

1. **跨 run 占位符**：如果用户在 Word 中手动编辑导致占位符被拆分到多个 XML run（如 `{{姓` + `名}}`），docxtemplater 无法识别，会报错提示用户修正
2. **格式保持**：docxtemplater 在 XML 层面替换文本，通常能保留格式。极端复杂的模板结构可能存在兼容性问题
3. **大文件内存**：浏览器处理大 Excel 文件有内存上限，V0.1 限制 500 行
4. **刷新丢失**：刷新页面需重新上传模板

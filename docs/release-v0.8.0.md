# Release v0.8.0

发布日期：2026-06-15

## 新增功能

### 变量填写体验优化

- 常用值记忆：单份生成和网页录入中支持保存和选择常用变量值
- 日期快捷填入：日期类变量显示"今天"按钮，一键填入 YYYY年M月D日
- 变量搜索：单份生成中支持按变量名搜索，快速定位变量
- 网页录入列填充：支持选择变量列并批量填充值到所有行
- 空值定位：网页录入校验后支持定位第一个错误单元格

## 功能一：常用值记忆

### 使用场景

用户经常填写的变量值（如单位名称、联系人、日期、文号等）可以保存为常用值，下次填写时快速选择。

### 操作步骤

1. 在输入框中填写变量值
2. 点击输入框右侧的保存按钮（图标）
3. 常用值保存成功后，输入框旁边显示常用值下拉选择
4. 选择常用值后自动填入
5. 在下拉菜单中可以删除常用值

### 限制

- 每个变量最多保存 10 个常用值
- 重复值不重复保存
- 常用值只保存在当前浏览器本地
- 清理浏览器数据后会丢失

### 存储

- 使用 localStorage 存储
- Key：`docxgen:fieldPresets`
- 数据结构：

```json
{
  "version": 1,
  "updatedAt": 1718467200000,
  "presets": {
    "单位名称": ["某某单位", "某某公司"],
    "日期": ["2026年6月15日"]
  }
}
```

## 功能二：日期快捷填入

### 识别规则

变量名包含以下关键词之一：

- 日期
- 时间
- date
- day

### 操作步骤

1. 在单份生成中，日期类变量显示"今天"按钮
2. 点击后填入当前日期
3. 默认格式：YYYY年M月D日（如：2026年6月15日）

### 说明

- 不强制把日期变量改成 DatePicker
- 保持普通文本输入框 + 快捷填入
- 格式符合公文习惯

## 功能三：变量搜索

### 操作步骤

1. 在单份生成区域顶部有搜索框
2. 输入变量名关键词
3. 只显示匹配的变量
4. 清空搜索后恢复全部变量
5. 没有匹配结果时显示"未找到匹配变量"

### 说明

- 搜索不影响实际生成数据
- 变量数量较少时也可显示搜索框

## 功能四：网页录入列填充

### 使用场景

某列（如"日期"）几十行都一样，用户不想一格一格填。

### 操作步骤

1. 在网页录入表格上方"批量填充列"区域
2. 选择变量列
3. 输入要填充的值
4. 点击"填充到全部行"
5. 日期列可以点击"填入今天"快捷按钮

### 说明

- 只填充已有行
- 空行也可以被填充
- 填充后给出提示

## 功能五：空值定位

### 网页录入

1. 校验后显示错误行和字段
2. 增加"定位第一个错误"按钮
3. 点击后滚动到第一个错误单元格
4. 错误行增加红色背景样式

### 说明

- 不影响当前已有错误行样式
- 滚动行为平滑

## 隐私说明

常用变量值仅保存在当前浏览器本地，不会上传服务器。清理浏览器数据后会丢失。

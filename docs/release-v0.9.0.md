# Release v0.9.0

发布日期：2026-06-15

## 新增功能

### 模板体检与错误诊断

- 上传模板后自动检查模板质量
- 体检结果分级展示：错误(error)、警告(warning)、提示(info)
- 手动点击"重新体检"功能
- 体检结果卡片，支持展开/收起详情
- 体检异常时生成前风险提示

## 检查项目

### 错误 (error)

| 检查项 | 说明 |
|--------|------|
| 无变量模板 | 模板中未识别到变量，无法生成可替换内容 |
| 非法变量名 | 变量名包含非法字符，只允许中文、英文、数字和下划线 |
| 未闭合占位符 | 检测到未闭合的「{{」或孤立的「}}」 |

### 警告 (warning)

| 检查项 | 说明 |
|--------|------|
| 跨 run 占位符 | 变量可能被 Word 拆分为多个文本节点 |
| 相似变量名 | 变量名高度相似，可能是误写 |

### 提示 (info)

| 检查项 | 说明 |
|--------|------|
| 重复变量 | 同一变量在模板中出现多次 |
| 变量数量较多 | 变量数量超过 20 个 |
| 页眉页脚变量 | 模板的页眉或页脚中包含变量 |

## 页面展示

### 体检结果卡片

- 总体状态：体检通过 / 存在警告 / 存在错误
- 统计：错误数量、警告数量、提示数量
- 结果列表：图标、标题、说明、修复建议
- 操作按钮：重新体检、展开/收起详情

### 交互流程

1. 上传模板后自动体检
2. 从本地模板库选择模板后自动体检
3. 体检结果不阻止用户查看变量清单
4. 存在 error 时，生成前显示风险提示

## 修复建议示例

### 无变量模板

> 请在 Word 模板中使用 {{变量名}} 格式添加变量，例如 {{姓名}}、{{日期}}。

### 非法变量名

> 请改为合法的变量名，例如将「单位-名称」改为「单位_名称」。

### 跨 run 占位符

> 请删除该占位符后，在 Word 中一次性重新输入完整变量，例如 {{姓名}}。

## 限制说明

- 不能保证发现所有 Word 内部拆分问题
- 体检通过不代表 Word 最终排版完全无误
- 不支持自动修复模板
- 不支持 .doc 格式模板

# 文书模板生成器 V0.3.0 发布说明

发布日期：2026-06-14

## V0.3 新增功能

### 模板记忆

上传模板成功后，系统自动保存模板名称和变量清单到浏览器 localStorage。

刷新页面后，如果检测到上次模板记录，显示提示：

> 检测到上次使用的模板：{templateName}。由于浏览器安全限制，请重新上传该 .docx 模板后继续生成。系统仅保存模板名称和变量清单，不保存文件本体。

### 网页录入草稿自动保存

在网页录入表格中输入内容时，系统自动保存草稿：

- 表格内容变化后 debounce 2 秒自动保存
- 关闭页面时 beforeunload 兜底保存
- 只在存在非空数据时保存
- 草稿最多保存 500 行

### 草稿自动恢复

重新上传模板后，如果变量清单与上次草稿一致，自动恢复草稿数据。

如果变量不一致，提示：

> 当前模板变量与上次草稿不一致，未自动恢复草稿。

### 清空本地记录

页面提供「清空本地记录」按钮，一键清空：

- 最近模板信息
- 网页录入草稿
- 最近使用模式

### 隐私提示

页面底部显示：

> 本工具不会上传任何文件。模板文件不会被保存；草稿数据仅保存在当前浏览器 localStorage 中，可随时清空。

## localStorage 数据结构

| Key | 内容 |
|-----|------|
| `docxgen:lastTemplate` | 模板名称、变量清单、最后使用时间、最后模式 |
| `docxgen:manualDraft` | 变量清单、草稿行数据、保存时间 |

## 当前限制

- 不保存 `.docx` 文件本体（需重新上传）
- 换浏览器或换设备无法同步
- localStorage 有容量限制（通常 5-10MB）
- 刷新后需重新上传模板文件

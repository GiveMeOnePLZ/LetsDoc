# 文书模板生成器

本地浏览器运行的公文/文书批量生成工具。上传 `.docx` 模板，通过 `{{变量名}}` 占位符定义可变字段，支持手工填写、网页手工录入或 Excel 批量导入，生成保持原模板格式的 Word 文书。

所有文件处理均在浏览器中完成，不上传服务器，不保存数据。

## 支持的文件格式

| 类型 | 支持 | 不支持 | 说明 |
|------|------|--------|------|
| 模板 | `.docx` | `.doc` | .doc 需先另存为 .docx |
| 数据 | `.xlsx` | `.xls` | 网页录入无需 Excel |

## 启动命令

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`

## 构建命令

```bash
npm run build
```

产物在 `dist/` 目录。

## 模板制作方法

1. 在 Word 中创建 `.docx` 文件
2. 在需要替换的位置输入 `{{变量名}}`，例如 `{{姓名}}`、`{{日期}}`
3. 变量名只允许：中文、英文、数字、下划线
4. 建议一次性输入完整占位符，不要分多次输入

### 正确示例

- `{{姓名}}`
- `{{单位名称}}`
- `{{日期}}`
- `{{doc_no}}`

### 错误示例

- `{{单位 名称}}`（变量名含空格）
- `{{单位-名称}}`（变量名含连字符）
- `{{}}`（空变量名）

## 单份生成流程

1. 上传 `.docx` 模板
2. 系统自动识别模板中的变量
3. 填写变量值
4. 点击「生成文书」
5. 下载生成的 `.docx` 文件

## 批量生成流程

### 方式一：网页手工录入

1. 上传 `.docx` 模板
2. 在「批量生成」区域选择「网页录入」标签
3. 在可编辑表格中填写数据（每行一份文书）
4. 支持新增行、复制上一行、删除行、清空数据
5. 支持从 Excel 复制多行多列后粘贴到表格
6. 点击「校验数据」检查空值
7. 点击「批量生成」下载 `.zip` 文件

### 方式二：Excel 导入

1. 上传 `.docx` 模板
2. 在「批量生成」区域选择「Excel 导入」标签
3. 点击「下载数据模板」获取 Excel 模板（列头为变量名）
4. 或点击「下载示例 Excel」获取示例数据
5. 在 Excel 中填写数据（每行一份文书）
6. 上传填写好的 `.xlsx` 文件
7. 系统显示数据校验结果（行数、空值、缺失列等）
8. 点击「开始批量生成」
9. 下载打包的 `.zip` 文件

## 常见错误和解决方法

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| 模板中未发现占位符变量 | 模板中没有 `{{变量名}}` | 在 Word 中使用 `{{变量名}}` 格式 |
| 变量名 "xxx" 包含非法字符 | 变量名含有空格、连字符等 | 只使用中文、英文、数字、下划线 |
| 无法解析 .docx 文件 | 文件可能损坏或不是 .docx | 重新保存为 .docx 格式 |
| Excel 缺少以下变量列 | Excel 表头缺少模板中的变量 | 在 Excel 中补充缺失的列 |
| 第 N 行缺少必填值 | 某行的某个变量列为空 | 填写该行的空值列 |
| 当前版本最多支持一次生成 500 份 | Excel 数据超过 500 行 | 拆分 Excel 分批处理 |
| 模板渲染失败 | 占位符可能被 Word 拆分 | 删除占位符后重新一次性输入 |

## 当前限制

- 仅支持 `.docx` 模板，不支持 `.doc`
- 仅支持 `.xlsx` 数据文件，不支持 `.xls`
- 批量生成最多 500 行
- 不支持跨 XML run 的占位符（如 `{{姓` + `名}}`）
- 刷新页面需重新上传模板
- 不支持 PDF 导出
- 不支持在线编辑模板

## 关于 .doc 文件

当前版本不支持 `.doc` 格式模板。`.doc` 是旧版 Word 二进制格式，无法稳定通过当前技术方案处理。

如需使用 `.doc` 模板，请先用 Word/WPS/LibreOffice 打开文件，然后「另存为」选择 `.docx` 格式保存，再上传到本工具。

不建议在后续版本引入自动 `.doc` 转换，以免引入格式风险。

## 技术栈

- Vite + React 18 + TypeScript
- Ant Design 5
- docxtemplater（Word 模板渲染）
- PizZip（.docx 解压/打包）
- SheetJS（Excel 读写）
- JSZip（批量打包）
- FileSaver（文件下载）

## 分发与部署

本工具是纯前端应用，所有文件处理在浏览器中完成，用户文件不会上传到任何服务器。

### 生产构建

```bash
npm run build
```

构建产物在 `dist/` 目录。

### 本地预览

```bash
npm run preview
```

浏览器打开 `http://localhost:4173` 预览生产构建。

### 静态部署

将 `dist/` 目录部署到任意静态网站服务即可：

- **公网部署**：GitHub Pages、Cloudflare Pages、Netlify、Vercel
- **内网部署**：单位内网静态服务器、Nginx、Apache、IIS
- **本地使用**：建议通过 `npm run preview` 启动本地服务器

不建议直接双击 `dist/index.html` 使用（部分浏览器会限制本地文件的 API 访问）。

非技术用户只需访问部署后的网址即可使用。

详细部署指南见 [docs/deploy.md](docs/deploy.md)。

# Release v0.6.0（现命名为 Doclet）

发布日期：2026-06-15

## 新增功能

### 本地模板库

- 基于 IndexedDB 保存 `.docx` 模板文件本体
- 支持保存、选择、重命名、删除、清空模板
- 上传模板后可保存到本地模板库
- 模板库列表显示模板名称、原文件名、变量数量、更新时间
- 支持手动刷新模板列表

### 界面优化

- 合并单份生成和批量生成界面，统一为"生成文书"
- 默认网页录入行数从 3 行改为 1 行
- 模板上传区域增加"保存到本地模板库"按钮

## 数据存储

### IndexedDB 数据结构

- 数据库名称：`docxgen-db`
- 版本：1
- 对象存储：`templates`
- 主键：`id`
- 索引：`updatedAt`、`name`

### 存储内容

- 模板文件本体（Blob 格式）
- 模板名称
- 原始文件名
- 变量清单
- 文件大小
- 创建时间和更新时间

## 使用说明

### 保存模板

1. 上传 `.docx` 模板文件
2. 系统自动识别变量
3. 点击「保存到本地模板库」按钮
4. 模板保存到浏览器 IndexedDB

### 使用模板库

1. 打开网页，在「本地模板库」区域查看已保存模板
2. 点击「选择」按钮加载模板
3. 系统恢复模板文件和变量清单
4. 直接填写数据或恢复草稿
5. 生成文书

### 管理模板

- **重命名**：点击编辑图标修改模板名称
- **删除**：点击删除图标移除单个模板（需二次确认）
- **清空**：点击「清空」按钮移除所有模板（需二次确认）
- **刷新**：点击「刷新」按钮更新模板列表

## 隐私说明

- 模板文件保存在当前浏览器 IndexedDB 中
- 不会上传到任何服务器
- 清理浏览器数据、换电脑或换浏览器后，模板库可能丢失
- 建议保留原始 `.docx` 文件备份

## 行为说明

### 保存同一模板多次

同名模板会被覆盖更新，不会产生重复记录。系统按模板名称查找已有记录，如果存在则更新，否则新建。

### 删除当前使用的模板

模板从库中删除，但当前内存中的模板仍可继续使用，直到刷新页面。系统会给出提示："已删除当前使用的模板，模板仍可继续使用直到刷新页面"。

### 清空模板库

所有模板从库中删除，当前使用的模板仍可继续使用，直到刷新页面。系统会给出提示："模板库已清空，当前使用的模板仍可继续使用直到刷新页面"。

## 限制说明

- 仅支持 `.docx` 模板文件
- 模板库数据仅保存在当前浏览器
- 换浏览器或清理数据会导致模板库丢失
- 建议保留原始文件备份
